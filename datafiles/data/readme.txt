dialogue and language data is stored here

STEPS TO ADD CUSTOM LANGUAGE:
1. In lang folder duplicate 'en' folder and rename it to your language
2. in your language folder rename the CSV inside that's titled 'en' to your language folders name
3. If your language requires a different font, delete the one in the folder and replace it with a font that will fit your language. Make sure the font is named 'def' and is a .tff file. 
3b. If there is more then one font in the default language folder, make sure to add subsequent ones with the same names.
4. in your language folder edit the flag image file to your flag
5. Edit the CSV files text to translate. (do NOT change anything in key column)
6. When booting up the game check if your language is in settings.
7. If so, switch to your language.
